# Exercícios Básicos de C#

Repositório destinado à prática dos fundamentos da linguagem C#, com exercícios focados em lógica de programação, estruturas condicionais, operações, entrada de dados e estruturas de repetição.

## Exercícios

1. Leia dois números e mostre a soma deles.
2. Leia três notas e calcule a média.
3. Leia um número e informe se ele é par ou ímpar.
4. Leia dois números e informe qual é o maior.
5. Leia a idade de uma pessoa e informe se ela é maior ou menor de idade.
6. Leia uma nota e informe se o aluno foi aprovado, ficou de recuperação ou foi reprovado.
7. Mostre os números de 1 até 100 utilizando `for`.
8. Mostre a tabuada de um número informado pelo usuário.
9. Leia 5 números e mostre o maior deles.
10. Crie uma calculadora que peça dois números e uma operação (`+`, `-`, `*` ou `/`) e mostre o resultado.
